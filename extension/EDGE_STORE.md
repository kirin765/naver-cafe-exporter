# Microsoft Edge 제출 — 네이버 카페 엑셀 내보내기

업로드 파일: `naver-cafe-exporter-v0.1.0-edge.zip` (Chrome과 동일 MV3 빌드)

## 절차
1. https://partner.microsoft.com/dashboard/microsoftedge/ 로그인(개발자 등록 필요).
2. **새 확장 프로그램 만들기** → zip 업로드.
3. 등록정보: `STORE_LISTING.md`의 이름/요약/설명 재사용.
   - 카테고리: 생산성, 언어: 한국어
   - 개인정보처리방침 URL: `https://naver-cafe-exporter.onnurimun.com/privacy`
   - 홈페이지: `https://naver-cafe-exporter.onnurimun.com/`
4. 권한 사유: `STORE_LISTING.md`의 "권한 사유" 문구 재사용.
5. 스크린샷: `store-assets/screenshot-1-workspace.png` (Edge는 1280×800 권장, 640×400 허용).
6. 제출 → 심사.

## 참고
- Edge Partner Center는 Chrome과 별개 계정입니다.
- 심사 반려 예방 주의사항은 `STORE_LISTING.md` 하단과 동일.

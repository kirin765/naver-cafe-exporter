# Naver Whale 스토어 제출 — 네이버 카페 엑셀 내보내기

업로드 파일: `naver-cafe-exporter-v0.1.0-whale.zip` (Chrome과 동일 MV3 빌드)

## 절차
1. https://store.whale.naver.com/ 에 네이버 계정으로 로그인 → 개발자 등록.
2. **확장 앱 등록** → zip 업로드.
3. 등록정보: `STORE_LISTING.md`의 이름/요약/설명 재사용.
   - 개인정보처리방침 URL: `https://naver-cafe-exporter.onnurimun.com/privacy`
4. 스크린샷: `store-assets/screenshot-1-workspace.png`.
5. 검수 요청.

## 참고
- Whale은 Chromium 기반이라 별도 빌드가 필요 없다(동일 zip 사용).
- 네이버 계정 로그인이 필요하며, 스토어 정책은 웨일 개발자센터 기준을 따른다.

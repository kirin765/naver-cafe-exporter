- [ ] **회원 디렉터리 판정** — 검증 성공 시에만 릴리스. 실패 시 첫 릴리스에서 명시적 제외.
- [ ] **Paddle** — 샌드박스 → 라이브 키/상품/가격/웹훅 분리, `tax_mode: internal`의
      ₩4,900 세금 포함 동작 확인, 소액 결제 수수료 계약 확인.
- [x] **도메인/호스팅** — `https://naver-cafe-exporter.onnurimun.com`를 apps VPS
      (systemd `app-naver-cafe-exporter`, 127.0.0.1:3016) + Cloudflare tunnel로 서비스.
      상세·배포 절차: `docs/deploy.md`.
- [x] **인증(magic-link)** — Clerk 대신 이메일 magic-link. VPS SMTP(Gmail 앱
      비밀번호)로 실제 발송 확인. `DEV_LOG_EMAIL=false`.
- [x] **Paddle 웹훅** — `.../api/webhooks/paddle` 서명 검증 라이브 확인(정상 200/
      중복 200/위조 401). `PADDLE_WEBHOOK_SECRET` 설정, 가격 ₩4,900/월 tax internal.
- [ ] **성능 벤치마크** — 5,000 게시글/50,000 댓글/20,000 회원, 100MB 텍스트 예산에서
      진행률 응답성·엑셀 취소·부분 결과 복구 확인 후 한도 확정.
- [ ] **브라우저 스모크** — Chrome 우선, Edge·Whale을 **각각** 확인한 뒤에만 지원 주장.
- [ ] **네트워크 검사** — 수집 페이로드·쿠키가 제품 백엔드/분석으로 전송되지 않음을 확인.
- [ ] **리텐션/저장공간** — 7일·5건 정책, `navigator.storage.persist()` 결과, quota 실패 시
      체크포인트 보존 동작 확인.

## 권한 설명 (스토어용)

| 권한 | 이유 |
| --- | --- |
| `activeTab` | 사용자가 실행한 카페 탭에서만 동작 |
| `scripting` | 카페 페이지에 캡처 훅 주입(MAIN world) |
| `storage` | 수집 내역·설정·계정 토큰(익스텐션 로컬) |
| `unlimitedStorage` | 장기 수집 시 IndexedDB 용량 확보 |
| host `cafe.naver.com`, `m.cafe.naver.com` | 카페 페이지 읽기/감지 |
| host `제품 도메인` | 계정·구독 권한 확인 API 호출 |

> `*.naver.com` 전체, 쿠키, 방문 기록, 디버거 권한은 사용하지 않는다.

## 스토어 요약 문구 (초안)

- **이름:** 네이버 카페 엑셀 내보내기
- **한 줄:** 카페 게시글·댓글·작성자(권한 시 회원)를 엑셀(.xlsx)로 저장합니다. 수집
  데이터는 내 컴퓨터에만 남습니다.
- **설명(핵심):**
  - 현재 열어 둔 카페·게시판을 감지해 공개 콘텐츠를 로그인 없이 수집
  - 날짜 범위·게시글 수·댓글·본문·회원(권한 시) 선택
  - 작성자/아이디 식별자 유형(멤버키·표시ID·마스킹·닉네임만)을 구분해 기록
  - 미리보기(무료 20개), 일시정지/재개, 접근 권한 재확인 후 재수집, 부분 내보내기
  - 여러 시트 엑셀 + `내보내기 정보` 시트(건수·한도·보류/제외)
- **금지/고지:** 마스킹·불완전 식별자 고지, 회원 디렉터리와 관측 작성자의 구분,
  로그인/캡차 우회·숨김/삭제 데이터 접근·연락처 재판매 불가.

## 가격·환불 정책 (초안)

- 월 ₩4,900, 매월 자동 결제, 언제든 다음 결제 해지.
- 정기 결제 종료 후에도 **이미 저장된 로컬 결과 다운로드는 유지**.
- 전체 환불(현재 결제 기간 커버)·차지백은 해당 기간 수집 권한을 회수하고 구독 취소를
  시도한다. 부분/이력 기간 환불, 승인 대기·거절 환불은 무관한 현재 기간을 회수하지 않는다.
- 유예: 갱신 실패 시 첫 실패로부터 3일. 유예 종료·정지·해지 후에는 미리보기만.
